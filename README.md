# Trabajo Tutelado - SE 24/25

Implementar una alarma con el temporizador LPTMR

El programa consta de 3 fases:

1. _Establecer valor de segundos a contar_, indicado con el **led verde** -> Aumentar valor con **botón izquierdo**, confirmar con **botón derecho**
2. _Establecer valor de alarma_, indicado con el **led rojo** -> Aumentar valor con **botón izquierdo**, confirmar con **botón derecho**
3. _Cuenta atrás_ -> Pausar/reanudar con **botón izquierdo**
